01 / FOUNDATION

One primitive, many effects.

Read viewport coordinates once, store them, and let one animation frame update decorative layers. The visual treatment changes; the architecture stays stable.

INPUT

clientX / clientY

Viewport-relative pointer coordinates pair naturally with fixed-position followers.

STATE

Store, don’t render

The pointer handler records a target. It should not perform every visual write itself.

FRAME

requestAnimationFrame

Interpolate toward the target and write transforms once per screen frame.

OUTPUT

Transforms or CSS vars

Move followers with transforms. Feed local spotlights through --x and --y.

02 / RECIPES

Build it from scratch.

These vanilla patterns cover the core effect shown in cursor-tracking reels and the most useful extensions. Copy a recipe, then tune the numbers to your project.

A. DOT + RING

Fixed followers

Center both shapes on the pointer and let clicks pass through them.

<div class="cursor-dot"></div>
<div class="cursor-ring"></div>

.cursor-dot, .cursor-ring {
  position: fixed;
  top: 0; left: 0;
  pointer-events: none;
  border-radius: 50%;
  will-change: transform;
}

const mouse = { x: innerWidth/2, y: innerHeight/2 };
addEventListener('mousemove', e => {
  mouse.x = e.clientX;
  mouse.y = e.clientY;
}, { passive: true });

B. LERP LOOP

Smooth trailing

A tight dot and a loose ring create the familiar premium lag.

const lerp = (a, b, t) => a + (b - a) * t;
let dotPos = {...mouse};
let ringPos = {...mouse};

function frame() {
  dotPos.x = lerp(dotPos.x, mouse.x, .35);
  dotPos.y = lerp(dotPos.y, mouse.y, .35);
  ringPos.x = lerp(ringPos.x, mouse.x, .12);
  ringPos.y = lerp(ringPos.y, mouse.y, .12);

  dot.style.transform =
    `translate3d(${dotPos.x}px,${dotPos.y}px,0)
     translate(-50%,-50%)`;
  ring.style.transform =
    `translate3d(${ringPos.x}px,${ringPos.y}px,0)
     translate(-50%,-50%)`;
  requestAnimationFrame(frame);
}
frame();

C. SPOTLIGHT

Gradient at the pointer

Set two custom properties and let CSS place a radial gradient.

.spotlight {
  background: radial-gradient(
    600px circle at var(--x, 50%) var(--y, 50%),
    rgb(8 127 140 / .18),
    transparent 70%
  );
}

const root = document.documentElement;
addEventListener('mousemove', e => {
  root.style.setProperty('--x', e.clientX + 'px');
  root.style.setProperty('--y', e.clientY + 'px');
}, { passive: true });

D. CARD-LOCAL

Glow and 3D tilt

Subtract the card’s bounding box to get coordinates inside the card.

card.addEventListener('mousemove', e => {
  const r = card.getBoundingClientRect();
  const x = e.clientX - r.left;
  const y = e.clientY - r.top;
  card.style.setProperty('--mx', x + 'px');
  card.style.setProperty('--my', y + 'px');

  const px = x / r.width - .5;
  const py = y / r.height - .5;
  card.style.transform = `perspective(800px)
    rotateY(${px * 12}deg)
    rotateX(${-py * 12}deg)`;
});
The key: event coordinate − rect edge gives the local pointer position.
E. MAGNETIC BUTTON

Pull toward the pointer, then snap home

Measure from the element’s center, multiply by a restrained strength, and transform the visual layer.

button.addEventListener('mousemove', e => {
  const r = button.getBoundingClientRect();
  const x = e.clientX - (r.left + r.width / 2);
  const y = e.clientY - (r.top + r.height / 2);
  const strength = .35; // .25–.4 is a practical range

  button.style.transform =
    `translate(${x * strength}px, ${y * strength}px)`;
});

button.addEventListener('mouseleave', () => {
  button.style.transition =
    'transform .5s cubic-bezier(.22,1,.36,1)';
  button.style.transform = 'translate(0,0)';
});

F. GSAP OPTION

Use quickTo when GSAP is already installed

It re-targets a cached tween instead of creating a new tween for every pointer event.

gsap.set([dot, ring], { xPercent: -50, yPercent: -50 });
const dotX = gsap.quickTo(dot, 'x', { duration: .15, ease: 'power3' });
const dotY = gsap.quickTo(dot, 'y', { duration: .15, ease: 'power3' });
const ringX = gsap.quickTo(ring, 'x', { duration: .5, ease: 'power3' });
const ringY = gsap.quickTo(ring, 'y', { duration: .5, ease: 'power3' });

addEventListener('mousemove', e => {
  dotX(e.clientX); dotY(e.clientY);
  ringX(e.clientX); ringY(e.clientY);
});

The reliable architecture

Pointer events update a tiny target object. One requestAnimationFrame loop reads it, interpolates current values, and writes transforms. Card-local gradients may write CSS variables directly, but frameworks should still avoid storing pointer position in rendered state.

04 / SHIP SAFELY

Performance and accessibility are part of the effect.

A cursor flourish is progressive enhancement. The page must remain usable when the flourish is off.

  • 01
    Gate on a real mouse

    Initialize only when (hover: hover) and (pointer: fine) matches. Touch has no cursor.

  • 02
    Honor reduced motion

    Disable trails, lag and magnetic pull when prefers-reduced-motion: reduce is active.

  • 03
    Never intercept clicks

    Every decorative follower or canvas needs pointer-events: none.

  • 04
    Transform, don’t position

    Animate translate3d(), not top or left, to avoid layout work.

  • 05
    Hide native conditionally

    Only apply cursor: none after the custom cursor is active. Consider excluding text inputs and selects.

  • 06
    Keep the click point honest

    The decorative ring may lag. Interaction and hover still come from the real pointer position.

  • 07
    Cap canvas work

    Limit particle count and reset canvas pixel dimensions after resize so the output stays crisp.

  • 08
    Clean up frameworks

    Remove listeners and cancel animation frames on unmount. Do not put mouse coordinates in React state.
